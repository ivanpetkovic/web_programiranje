# Režim ventilatora je uključen ili isključen

Ventilator koji se vrti sugeriše skalu brzina. Kurs ipak drži režim na dve vrednosti, jer pitalica o ponavljanju poredi „postavi na uključeno” i „prebaci stanje”. Treća brzina bi uvela novo pravilo pre nego što boolean komanda bude jasna. Trajanje CSS animacije i dalje sme da se menja kad se uči transformacija; to nije režim.
