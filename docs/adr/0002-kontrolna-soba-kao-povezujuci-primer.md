# Kontrolna soba kao povezujući primer

Izabrana je Kontrolna soba sa simuliranim staklenikom, početno jednim očitavanjem i jednim ventilatorom. U poređenju sa Reaktorom i igrom kretanja po tabli, prirodnije podržava diskusiju o zastarelim podacima, ponovljenim komandama, korisničkim ulogama i promenama na serveru; dodatna složenost ograničava se postupnim uvođenjem pojmova. Predavanja demonstriraju koncepte kroz pripremljene scenarije i pitalice, uz vanilla browser JS, Node.js bez web framework-a i PostgreSQL u Dockeru.
