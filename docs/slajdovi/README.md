# Slajdovi za predavanja

Izvorni tekst slajdova drži se u Marp fajlovima (`*.marp.md`). Iz njih se može izvesti PPTX sa beleškama prezentera:

```bash
npx --yes @marp-team/marp-cli@latest docs/slajdovi/cas-02-javascript-osnove.marp.md --pptx -o docs/slajdovi/cas-02-javascript-osnove.pptx
```

Pravila formatiranja su u glavnom planu kursa, odeljak **Nastavni obrazac**.
